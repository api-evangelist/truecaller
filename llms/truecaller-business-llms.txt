## Verified Business APIs

- [Getting Started](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/getting-started.md): Welcome to the API Documentation for our Verified Business Caller ID Solution!
- [Authentication](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/getting-started/authentication.md): This page provides the steps to generate the Key ID and Secret API Key.
- [Generate Access Token](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/getting-started/generate-access-token.md): This API is used to generate an access token using the Key ID and Secret API Key created from the Manage API Keys page
- [Call Personalisation](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/call-personalisation.md)
- [Call Personalisation Real-time v2](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/call-personalisation/call-personalisation-real-time-v2.md): Real-time synchronous API to personalize calls for a given Caller-Receiver combination
- [Call Personalisation Batch v2](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/call-personalisation/call-personalisation-batch-v2.md): This endpoint pushes the dynamic caller ID details to the respective TC users.
- [Call Personalization Batch v2 Status](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/call-personalisation/call-personalization-batch-v2-status.md): Each record indicates whether the record was successfully pushed or not.
- [Details of Dynamic Label](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/call-personalisation/details-of-dynamic-label.md): This API is used to get the details of the Dynamic Labels created on the Truecaller
- [Call Personalisation Errors](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/call-personalisation/call-personalisation-errors.md): You can find explanations for errors related to Call Reason in this section.
- [Number Management](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/number-management.md)
- [List Number](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/number-management/list-number.md): This API is used to list the business numbers on the Truecaller Portal
- [DeList Number](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/number-management/delist-number.md): This API is used to delist and remove business numbers from the client account and its feature-set.
- [Number details](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/number-management/number-details.md): This API is used to get meta-data of listed business numbers.
- [Feature-set ID](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/number-management/feature-set-id.md): This API is used to get feature-set ID to list and delist numbers.
- [Webhooks](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/webhooks.md)
- [Webhook Configuration](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/webhooks/webhook-configuration.md)
- [Event Types](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/webhooks/event-types.md): We support Call Me Back and User Feedback events for webhooks. Each event has its resources that can be referred from the resource column.
- [Webhook Timeouts](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/webhooks/webhook-timeouts.md)
- [Error scenarios for Webhooks](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/webhooks/error-scenarios-for-webhooks.md): This page list the errors which we can encounter while using the webhooks.
- [Deprecated API's](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/deprecated-apis.md): This Page lists all the Deprecated API which should not be used for new customers.
- [Call Personalisation Real-time API](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/deprecated-apis/call-personalisation-real-time-api.md): Sync API to send call personalisation data for a Caller-Receiver combination. This is a real-time API
- [Call Personalisation (Bulk)](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/deprecated-apis/call-personalisation-bulk.md): Async API to send call personalisation data for a Caller-Receiver combination
- [Batch Status](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/deprecated-apis/batch-status.md): Fetch status of records for Batch-ID returned in the Bulk Call Personalisation API.
- [User Feedback](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/deprecated-apis/user-feedback.md): The User Feedback API helps you to download logs for User Feedback campaigns running on the numbers where this feature has been enabled
- [Call Me Back](https://docs.truecaller.com/truecaller-for-business/verified-business-api-documentation/deprecated-apis/call-me-back.md): The Call Me Back API helps you to download Call Me Back requests for the numbers for which this feature has been enabled.
